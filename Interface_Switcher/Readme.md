The Interface_Switcher project aims to connect Trello columns based on defined rules and Google Sheets tables. 
The INTSWTCH function has only one-way functionality to copy card content from Trello columns and create a database. 
Any edits are reflected in real-time and update the table. 
If it is not possible to obtain the Trello API, an alternative would be to create a web form that would generate 
a database from the entered data.
